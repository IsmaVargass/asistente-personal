1 Introducción al Concepto de Función en Python

En programación modular, una función es un bloque de código independiente y reutilizable diseñado para realizar una tarea específica. En lugar de duplicar instrucciones, se define una única vez mediante la palabra reservada def y se invoca las veces necesarias (cumpliendo el principio DRY: Don't Repeat Yourself).

📦 Parámetros y Argumentos

El parámetro es la variable declarada en la cabecera. El argumento es el dato real inyectado durante la invocación.

🔄 Valor de Retorno (return)

Sentencia que finaliza la función y devuelve un resultado procesado al llamador, aislando el cálculo de la interfaz gráfica o consola.

🛡️ Ámbito (Scope Local)

Las variables creadas dentro de una función viven en su memoria local y mueren al terminar, evitando colisiones con variables globales.

5 Solución Recursiva: Pila de Llamadas y Caso Base

Fundamento: Toda función recursiva debe garantizar un caso base (condición de parada). En su defecto, se produce una recursión infinita agotando el límite de la pila de memoria (RecursionError).

Traza paso a paso de calcular_factorial(4):

1️⃣ factorial(4) = 4 * factorial(3) ⬇️ Apila llamada en espera
2️⃣ factorial(3) = 3 * factorial(2) ⬇️ Apila llamada en espera
3️⃣ factorial(2) = 2 * factorial(1) ⬇️ Apila llamada en espera
🎯 factorial(1) = 1 (¡CASO BASE ALCANZADO!) 🛑 Detiene llamadas
4️⃣ Desapila: 2 * 1 = 2  |  3 * 2 = 6  |  4 * 6 = 24 ⬆️ Retorno final = 24

Nota técnica sobre Fibonacci: Se advierte en el proyecto que su versión recursiva tiene coste exponencial $O(2^n)$ al repetir llamadas idénticas; por seguridad se limitó a $n \le 30$.

6 Aplicación y Justificación de Funciones Lambda

Una Lambda es una función anónima compacta: lambda arg: expresión. Equivale a las arrow functions de JavaScript (x => x * 2).

  • Ordenación en caliente: sorted(agenda, key=lambda c: c["nombre"].lower()) permite ordenar sin distinguir mayúsculas/minúsculas sin crear funciones def auxiliares desechables.
  • Filtrado funcional: list(filter(lambda p: p["stock"] <= 5, inventario)) extrae en una sola línea los artículos que requieren reposición inmediata.
  • Mapeo de datos: list(map(lambda p: round(p * 0.8, 2), precios)) transforma colecciones completas aplicando descuentos masivos.

7 Principales Dificultades Encontradas y Soluciones

1. Validación de Entradas de Usuario

Problema: Al pedir números con input(), si el usuario escribe letras el programa lanza ValueError y se detiene.
Solución: Se crearon funciones modulares (pedir_numero, pedir_entero) con bucle while True y try/except que insisten hasta recibir un dato correcto.

2. Pila de Llamadas en Fibonacci

Problema: Con números superiores a 35, la recursividad pura colapsa la consola por su complejidad exponencial.
Solución: Se acotó la entrada a un máximo de $n = 30$ y se explicó en código la diferencia entre el caso base y el crecimiento de la pila.

3. Manejo de Stock Negativo

Problema: Al descontar unidades vendidas se corría el riesgo de dejar existencias en valores inferiores a cero.
Solución: Se diseñó actualizar_stock() devolviendo una tupla (exito, stock, mensaje) que aborta la operación si el stock resultante sería negativo.

4. Cierre Inesperado con Ctrl + C

Problema: Si el usuario pulsa Ctrl + C para salir rápido, Python muestra una traza de error KeyboardInterrupt.
Solución: Se envolvió el bucle principal en un bloque try/except KeyboardInterrupt para imprimir una despedida amistosa y salir con código 0.
